# Hi, I'm Ahmed 👋

**Backend / Full-Stack Software Engineer** based in Lahore, Pakistan.
4 years building production backend systems in **Python (Django)** and **Java (Spring Boot)**, deployed on **AWS** and **GCP**.

I design the parts of a system that have to keep working when things get busy: data models, async pipelines, real-time sync, and infrastructure as code. Lately I've been building AI-powered apps too.

## What I work on

- **Backend architecture:** REST APIs, role- and permission-based systems, multi-stage approval workflows
- **Async processing:** Celery, Redis, RabbitMQ, BullMQ
- **Data:** PostgreSQL schema design, plus real-time sync between Postgres and Firebase Firestore
- **Infrastructure:** Terraform, Docker, Kubernetes, Jenkins and CI/CD on AWS (Fargate, S3, ElastiCache) and GCP
- **Domains I've shipped in:** CMS platforms, e-commerce and rental marketplaces, subscription billing (Stripe, m3ter), analytics and KPI reporting
